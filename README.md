# LeadPilot AI

Минимальный Telegram-продавец для образовательного бизнеса. Python 3.12+, без внешних зависимостей. Это сценарный MVP, языковая модель пока не подключена.

## Возможности

- Согласие перед сохранением переписки, кнопки ответов, семь последовательных вопросов.
- Подбор по цели из `catalog.json`; без подтверждённых данных — предложение обратиться к менеджеру.
- SQLite: ответы, история и статус заявки сохраняются между запусками.
- Передача менеджеру Telegram ID, ответов и истории по запросу или при жалобе/возврате.
- `/stop` останавливает диалог, `/start` начинает заново, `/delete` удаляет запись из локальной базы.

## Быстрая проверка

```powershell
python bot.py --demo
```

Введите `/start`, затем `Согласен`. Выход: `/quit`.

## Telegram

Создайте бота через @BotFather. Менеджер должен сначала написать боту; получите ID его приватного чата. Задайте переменные в текущем терминале:

```powershell
$env:TELEGRAM_BOT_TOKEN = 'токен-бота'
$env:MANAGER_CHAT_ID = 'id-чата-менеджера'
python bot.py
```

`.env.example` — только образец: автоматической загрузки `.env` нет. Токены и база исключены из Git. Запускайте один экземпляр, без установленного webhook. Компьютер должен оставаться включённым.

Заполните `catalog.json` реальными продуктами:

```json
{"products": [{"name": "Название", "goal": "Для работы", "description": "Подтверждённое описание результата", "price": "Утверждённая цена"}]}
```

`goal` должен совпадать с ответом клиента. При нескольких совпадениях показывается первое предложение; бюджет и уровень пока собираются для менеджера, но не участвуют в подборе.

## Границы MVP

Нет LLM, CRM, календаря, платежей, голосовых, автоматических касаний и аналитической панели. Поддерживается русский текст. Передача — уведомление менеджеру; отвечать клиенту менеджер должен самостоятельно. Дополнения после передачи сохраняются в базе, повторно менеджеру не отправляются. Очереди гарантированной доставки и постоянного offset пока нет: при сетевом сбое возможны пропущенные уведомления или повторы. Контекст отправляется частями.

Данные находятся в `leads.db` на машине запуска и в Telegram после передачи. `/delete` удаляет только локальную запись, а не сообщения Telegram или резервные копии. Перед реальными клиентами настройте условия обработки данных, сроки хранения, доступ и резервное копирование у оператора. Не храните базу в публичном репозитории.

API: [официальная документация Telegram](https://core.telegram.org/bots/api).
